# Pokedex CLI

A Pokedex CLI built in Go with functionalities like viewing locations, viewing pokemon in locations, catching pokemon, and inspecting caught pokemon.

## Commands
- pokedex: Track Pokemon you have caught
- exit: Exit the Pokedex
- help: Displays a help message
- map: Displays 20 location areas in the Pokemon world
- mapb: Displays previous 20 location areas in the Pokemon world
- explore: Explore Pokemon in a given location
- catch: Try to catch a Pokemon
- inspect: Inspect Pokemon you have caught
